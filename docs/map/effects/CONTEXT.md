# docs/map/effects/ — change-impact index (contract)

This file is the index itself, not a folder of cards. It answers one question: *if I am
changing X, what do I open?*

## Shape

A catalog. One row per change surface, each naming the cards and source files to open, plus
the single non-obvious thing that surface breaks.

## What does not belong here

- A waterfall dump of everything downstream. First-order impact only.
- Restated card content. This file routes to cards; it does not summarise them.
